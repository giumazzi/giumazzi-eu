# giumazzi.eu — sito di prova

Pagina statica (HTML + CSS, nessun JavaScript) pubblicata con GitHub Pages sul dominio `giumazzi.eu`.

- `index.html`, `style.css`, `404.html`: contenuto del sito.
- `CNAME`: dominio personalizzato per GitHub Pages.
- `robots.txt` e `<meta name="robots">`: il sito di prova non va indicizzato. Rimuovili quando il sito diventa definitivo.

Anteprima locale:

```bash
python3 -m http.server 8765
```
